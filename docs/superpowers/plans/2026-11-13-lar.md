# Lär Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** En femte flik "Lär" med ett bibliotek över åtta personer, deras idéer och källmärkta påståenden.

**Architecture:** Allt innehåll är fast, typad data i `src/lar/people.ts`. `src/lar/Lar.tsx` visar lista med områdesfilter och en personsida. Ingen databas, ingen synk, ingen server. Fliken kopplas in i `nav.ts` och `App.tsx` på samma sätt som Nyheter (lazy).

**Tech Stack:** Vite, React, TypeScript, vitest, Playwright för skärmbilder. Inga nya beroenden.

**Spec:** `docs/superpowers/specs/2026-11-13-lar-design.md`

## Global Constraints

- All kod för delen ligger i `src/lar/`, utom fliken i `src/nav.ts` och inkopplingen i `src/App.tsx`.
- Ekonomidelen rörs inte: inga ändringar i `db.ts`, `sync.ts`, ekonomikomponenter eller uträkningar.
- Inga påhittade citat: bara sammanfattningar med egna ord. Fältet för text får inte innehålla citattecken runt personens ord.
- Varje påstående har märkning `belagt` | `svagt` | `asikt` och minst en källa med `https://`-länk som har kontrollerats på nätet när den skrevs in. Går en länk inte att bekräfta tas påståendet bort.
- Märkningarnas text: "Väl belagt", "Svagt stöd", "Egen åsikt".
- Områden, exakt: "Andning och kyla", "Kallbad och bastu", "Meditation", "Personlig utveckling".
- Personer, exakt åtta: Wim Hof, Susanna Søberg, Jari Laukkanen, Andrew Huberman, Rhonda Patrick, Jon Kabat-Zinn, James Clear, Chris Williamson.
- Vardagsrummets stil: systemets typsnitt, färger bara via tokens (`--bg`, `--surface`, `--ink`, `--pine`, `--act` …), inga hex-värden i `lar.css`. Ljust och mörkt läge, 375 px och skrivbord ≥ 900 px.
- Svenska i all text. Inga tankstreck i gränssnittstext.
- Ingen AI, ingen tjänst som kostar, inga anrop ut från fliken (länkar öppnas i ny flik med `rel="noopener noreferrer"`).
- `npm test` och `npm run build` gröna före varje push. Pusha aldrig till `main`.

## Review Focus

1. Sparad vy `lar` i localStorage ska öppna Lär vid start; okänd vy ska fortfarande öppna Idag. (Task 2)
2. Filter som ger noll personer får inte ge en tom vit yta: tomt läge med text ska visas. (Task 3)
3. Långa namn och å/ä/ö/ø ("Susanna Søberg") får inte bryta kortet på 375 px. (Task 4, skärmbild)
4. Fem flikar ska få plats i bottenmenyn på 375 px utan att text klipps. (Task 4, skärmbild)
5. Personsida öppen + byte av flik och tillbaka: man ska hamna där man var, och Tillbaka ska leda till listan. (Task 3)

```ts
export type AreaId = 'andning' | 'kallbad' | 'meditation' | 'utveckling';
export const AREAS: { id: AreaId; label: string }[];
export type Evidence = 'belagt' | 'svagt' | 'asikt';
export const EVIDENCE_LABEL: Record<Evidence, string>;
export type Source = { title: string; url: string };
export type Claim = { text: string; evidence: Evidence; note?: string; sources: Source[] };
export type Person = {
  id: string;            // t.ex. 'wim-hof'
  name: string;
  kind: string;          // 'Forskare', 'Utövare', 'Poddare', 'Författare', 'Forskare och poddare'
  areas: AreaId[];
  teaser: string;        // en rad i listan: vad man lär sig
  about: string;         // 2–4 meningar: vem de är
  method: string[];      // metoden eller huvudidéerna, punktvis
  claims: Claim[];
  startHere: Source[];   // bok, studie eller avsnitt att börja med
  warning?: string;      // risker; krävs för personer i 'andning' och 'kallbad'
};
export const PEOPLE: Person[];
export const peopleIn: (area: AreaId | 'alla') => Person[];
export const personById: (id: string) => Person | undefined;
```

### Task 3: Vyn (`Lar.tsx`)

**Files:**
- Create: `src/lar/Lar.tsx`, `src/lar/lar.css`
- Modify: `src/App.tsx` (lazy-import bredvid Nyheter, en `<div hidden={view !== 'lar'}>` med `visited.has('lar')` och `Suspense fallback={<ViewLoading />}`)

**Interfaces:**
- Consumes: allt från `people.ts` (Task 1), `'lar'` i `View` (Task 2).
- Produces: `export default function Lar(): JSX.Element`.

Beteende:
- Lista: `view-intro` med eyebrow "Bibliotek" och `h2` "Lär". Under: chips för "Alla" och de fyra områdena (samma `chip`-klass och `aria-pressed` som Nyheter). Kort per person: namn, `kind`, `teaser`. Kortet är en `button`.
- Personsida (ersätter listan, eget state `openId`): knapp "Tillbaka", namn som `h2`, `kind` och områden, `about`, ev. `warning` i en tydlig ruta med `role="note"`, rubrik "Metod" med `method` som lista, rubrik "Påståenden" där varje påstående visar text, märkning som etikett (`EVIDENCE_LABEL`), ev. `note` och källorna som länkar, rubrik "Börja här" med `startHere`.
- Märkningen skiljs åt med både text och färg (`belagt` i `--pine`, `svagt` i en dämpad token, `asikt` neutral). Färg får aldrig vara enda skillnaden.
- Tomt filter (kan inte hända med dagens data men ska tåla det): texten "Inga personer i det här området än."
- Okänt `openId` (t.ex. efter att en person tagits bort): visa listan.
- Tillbaka sätter fokus på kortet man kom från. Sidan rullas till toppen när en person öppnas.
- Länkar: `target="_blank" rel="noopener noreferrer"`.
